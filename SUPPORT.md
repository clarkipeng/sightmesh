# Support

SightMesh is an experimental, community-maintained project. There is no uptime, response-time, compatibility, or production-support SLA.

- Use GitHub Discussions, when enabled, for setup and usage questions.
- Use a bug report for a reproducible defect in a supported version.
- Use a feature request for a bounded proposal consistent with the architecture.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

Include the SightMesh version or commit, macOS and Python versions, provider CLI names and versions, the redacted command, expected result, and actual result. Remove credentials, auth headers, tokens, private transcript content, and identifying local paths.

Only the latest tagged release and current `main` receive best-effort support. Provider account, billing, quota, and login problems remain the provider's responsibility. Maintainers may close requests involving unowned accounts, credential replay, session sharing, quota evasion, unsupported platforms, or production assurances.
